Quillrun, a byte-identical drop-in for makefun-site 1.0.0 in plain JavaScript with no dependencies. It uses a hand-written Markdown line lexer that copies plain text runs as slices, escapes and slugs only when a string needs it, and compiles each layout once per build into a JS function (includes inlined, constant fragments memoised). Locally that comes to about 1.6x less CPU than the baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
